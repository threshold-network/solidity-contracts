= Threshold network contracts

This package contains Threshold network contracts.

toc::[]

== Build, test and deploy

Threshold contracts use https://hardhat.org/[*Hardhat*] development environment.
To build and deploy these contracts, please follow the instructions presented
below.

=== Prerequisites

Please make sure you have the following prerequisites installed on your machine:

- https://nodejs.org[Node.js] 22.x (see `.nvmrc`)
- https://yarnpkg.com[Yarn] 1.22.22 (pinned in `package.json`)

=== Build contracts

To build the smart contracts, install node packages first:
```
yarn install
```
Once packages are installed, you can build the smart contracts using:
```
yarn build
```
Compiled contracts will land in the `build` directory.

=== Test contracts

There are multiple test scenarios living in the `test` directory.
You can run them by doing:
```
yarn test
```

=== Static analysis

CI runs https://github.com/crytic/slither[Slither] with Python 3.13 and the
versions pinned in `requirements-slither.txt`: Slither 0.11.6,
crytic-compile 0.4.2, and solc-select 1.2.0. To use the same tools locally,
install Python 3.13 and update the operating system's certificate trust store
before creating an isolated environment. On Ubuntu, update the signed package
indexes and installed CA bundle:

```
sudo apt-get update
sudo apt-get install --yes --only-upgrade ca-certificates
```

On other platforms, apply the current certificate trust updates through the
operating system's supported update mechanism. Both the system roots and pip's
bundled roots must be updated because pip trusts them together. Then create or
activate the virtual environment and bootstrap its Python certificate trust:

```
python3.13 -m venv .venv-slither
source .venv-slither/bin/activate
export PIP_CONSTRAINT="$PWD/constraints-python.txt"
export PIP_BUILD_CONSTRAINT="$PIP_CONSTRAINT"
python -m pip --disable-pip-version-check install --no-index --no-deps --no-cache-dir \
  'pip @ https://files.pythonhosted.org/packages/3f/06/3e4420302363fbb71be3c7f35ce042f54bfca330e3e66b3a2e3c4cca579f/pip-26.2.2-py3-none-any.whl#sha256=fd7f4dfa8190e014013b9f08f3e973f4e4c26ffd179a204895533a7254813a70'
python -m pip install certifi
python -m pip install -r requirements-slither.txt
python -m pip check
solc-select install 0.8.9
solc-select use 0.8.9
yarn install --frozen-lockfile
slither .
```

Bootstrap pip before installing other packages, including in an existing virtual
environment. The hash-pinned wheel and certificate constraints follow the
https://discuss.python.org/t/109576[Python eMudhra/emSign advisory]. Keep both
constraint variables set while installing tools so isolated build dependencies
use the same security floors.

Slither performs a clean Hardhat compilation with the OpenZeppelin upgrades
plugin enabled. The compiler remains Solidity 0.8.9, and
`slither.config.json` selects the `build` artifacts directory and the
repository's existing detector/path exclusions. The command fails on analysis
errors or any finding that has not been excluded or suppressed.

When upgrading, review the upstream release notes and Python requirements,
update the three pins together, and repeat the commands above in a fresh
environment. Run `slither . --warn-unused-ignores` to review obsolete inline
suppressions; investigate new findings and document any necessary suppression
at the affected code. Also run `yarn build`, `yarn test`, and `yarn format`.
CI prints the Python and analyzer tool versions for comparison with local runs.

=== Deploy contracts

To deploy all contracts on the given network, please run:
```
yarn deploy --network <network>
```

If contracts haven't been built yet or changes occurred, this task will build
the contracts before running the deployment script. This command produces
an `export.json` file containing contract deployment info.
