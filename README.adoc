= Threshold network contracts

This package contains Threshold network contracts.

toc::[]

== Build, test and deploy

Threshold contracts use https://hardhat.org/[*Hardhat*] development environment.
To build and deploy these contracts, please follow the instructions presented
below.

=== Prerequisites

Please make sure you have the following prerequisites installed on your machine:

- https://nodejs.org[Node.js] 22.x (see `.nvmrc`)
- https://yarnpkg.com[Yarn] 1.22.22 (pinned in `package.json`)

=== Build contracts

To build the smart contracts, install node packages first:
```
yarn install
```
Once packages are installed, you can build the smart contracts using:
```
yarn build
```
Compiled contracts will land in the `build` directory. The build also generates
ethers v5 contract types in `typechain`; these files should not be edited or
committed.

=== Test contracts

The tests in the `test` directory use TypeScript and generated contract types.
You can run them by doing:
```
yarn test
```

To regenerate contract types and check the tests, deployment scripts, tasks, and
Hardhat configuration with strict TypeScript settings, run:
```
yarn typecheck
```

`yarn format` runs type checking, linting, and formatting checks in CI. Linting
also rejects unhandled promises, so asynchronous setup and contract calls must
be awaited or returned. The package continues to export JavaScript deployment
scripts; tests and generated contract types are not published.

=== Deploy contracts

To deploy all contracts on the given network, please run:
```
yarn deploy --network <network>
```

If contracts haven't been built yet or changes occurred, this task will build
the contracts before running the deployment script. This command produces
an `export.json` file containing contract deployment info.

See link:docs/verification.adoc[deployment verification] for verifying maintained
contracts on Etherscan using the saved deployment records.
